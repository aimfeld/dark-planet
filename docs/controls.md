# Controls

The start screen picks the version (Classic 1998 or Remastered 2026) and the language; then the intro plays (any
key skips it). Main menu: arrows and Enter, or the mouse. The hangar works with the mouse: "Shoot em all" starts
the next level, "Multiplayer" adds player 2, and "Options" sets each player's controls (Keyboard, Mouse, Joystick =
gamepad, WASD or Touch). Each player's controls are listed below the picture.

## In a level

| Control | Move | Fire | High / low | Select bonus | Use bonus |
|---|---|---|---|---|---|
| Keyboard (arrows) | arrows | X | C | V | X+V |
| Keyboard, while a WASD player is in the game | arrows | , | . | - | , + - |
| WASD (player 2's default) | W A S D | X | C | V | X+V |
| Mouse | the jet follows the pointer | left | right | middle | left + middle |
| Gamepad | stick or d-pad | A / RT | B | X / LB / numpad − | Y / RB / numpad + |
| Touch (default on phones and tablets) | stick under the left thumb | button (double tap: autofire) | button | button | button |

The original's keys (Ctrl fires, Alt switches altitude, Space selects, Ctrl+Space uses) still work, but in a
window the desktop takes some of their combinations, so the legend doesn't list them (decision 15 in
[PLAN.md](PLAN.md)).

| Key | Action |
|---|---|
| P | pause (touch: ❚❚; ✕ in the pause ends the level) |
| Esc | abort to the menu |
| F | fullscreen (in Chrome with Keyboard Lock, so the desktop doesn't take Ctrl/Alt combinations) |
| R | switch between Classic and Remastered at any time (touch: the HD button) |

In the menus on a touch screen, tap the items; a long press is the right mouse button.

## Ctrl on a Mac
macOS takes Ctrl+arrows (Spaces, Mission Control) even in fullscreen. To fire with Ctrl, turn off "Mission
Control", "Application windows" and "Move left/right a space" in System Settings → Keyboard → Keyboard Shortcuts →
Mission Control. Or fire with X.

## Cheat
**GEDANKE** typed in the hangar sets both players' money to 666666. The cheat is in the original game, and the
remake keeps it in every build and language.
